# 会话启动输出模板

> 框架规则版本 10.3 | 2026-05-10 | 维护者：Thinker Agent
> Source Status: canonical
> Scope: 会话启动输出格式模板

天城每次新会话启动时的输出格式模板，包含各模块的展示规范。

---

## 开场白

```
呵呵，主上好。天城已启动。
```

---

## 输出区块规范

### 区块1：协作模式

```
当前模式：[单Agent / SubAgent模式 / Agent Teams模式]
可用Agent: baize | fuxi | luoshen | luban | laojun | cangjie | diting | taibai | puti | wukong | wenqu
专家Agent: hongjun/master（显式调用）
```

---

### 区块2：Agent Teams 支持

```
✓ 已启用 Leader 协调的多 SubAgent 模式
✓ 适用场景：并行审查、竞争假设调试、跨层协调、多角度研究
触发条件：需要队友间讨论/辩论/协作的复杂任务
使用方式：告诉天城"创建一个 agent team 来..."
```

---

### 区块3：项目状态

```
当前项目: [activeProject名称]
代码路径: [从 registry.json 读取]
知识体系: [已加载知识库、战术手册摘要]
```

---

### 区块4：已加载知识

```
开发规范: [X条规范已加载]
项目约定: [X条约定已加载]
高频技巧: [X条技巧已加载，按需加载其余]
```

---

### 区块5：环境感知（条件显示）

**显示条件**：项目配置了 `important: true` 的调试工具时显示。

```
✓ {工具名称} → {工具用途}
  - {关键信息}
  - 文档：{文档路径}
```

---

### 区块6：待办事项

```
(X项未完成)
按优先级和时间倒序列出
每项格式: [优先级] 简要描述... (创建时间) → 状态提示
```

---

## 结束语

```
请主上下达指令。
```

# 工具使用规则

> 框架规则版本 10.3 | 2026-05-10 | 维护者：Thinker Agent
> Source Status: canonical
> Scope: 工具选择、批量调用、Shell 与路径安全

工具使用规则，包括工具选择、跨平台环境规范和批量调用性能优化。部分约束已转化为Hook硬约束自动强制执行。

---

## 工具选择规则

优先使用专用工具，避免 standalone cat/grep/sed 等命令。

| 操作 | 首选工具 |
|------|---------|
| 读取文件 | Read 工具 |
| 编辑文件 | Edit 工具 |
| 搜索文件名 | Glob 工具 |
| 搜索文件内容 | Grep 工具 |
| 执行命令 | Bash |

---

## 批量工具调用规则

- 始终使用批量工具并发执行多个独立的工具调用
- 读取文件时使用Read工具，默认读取整个文件
- 编辑文件时始终使用Edit工具，编辑前必须先读取文件
- 运行bash命令前验证命令安全，使用精确路径
- 引用号包含空格的路径必须用双引号包裹

**性能优势**：批量工具调用可显著减少延迟。

```
总耗时 ≈ max(每个工具耗时)  而非  sum(每个工具耗时)
```

---

## 跨平台环境规范

| 规则 | 说明 |
|------|------|
| 环境变量语法 | 禁止依赖 Shell 变量展开（`$VAR_NAME`），使用绝对路径或 Python 脚本 |
| 路径分隔符 | 统一使用正斜杠 |
| 路径引号 | 包含空格的路径必须用双引号包裹 |

---

## 要点速览

- 批量工具调用可显著减少延迟：总耗时 ≈ max(每个工具耗时) 而非 sum(耗时)
- 优先使用专用工具（Read/Edit/Grep/Glob），避免standalone cat/grep/sed -i
- 禁止依赖 Shell 变量展开（$VAR_NAME），使用绝对路径或Python脚本
- 编辑前必须先读取文件，提供唯一的oldString避免模糊匹配
- 路径包含空格时必须用双引号包裹

# 视频分析输出质量与保存规则

本文件承接 `SKILL.md` 中压缩出的文档质量、保存整理、错误处理和参考标准。执行深度视频分析或技术文档生成时按需读取。

## 金字塔文档原则

```text
        ▲ 核心结论（一句话总结）
       ╱ ╲
      ╱   ╲ 关键价值（3-5 个要点）
     ╱─────╲
    ╱       ╲ 支撑细节（数据、案例、原理）
   ╱─────────╲
  ╱           ╲ 参考资源（论文、代码、文档）
 ╱─────────────╲
```

- 先给结论，再展开论证。
- 每层信息自成体系，读者可在任意层停止。
- 数据、对比和架构必须表格化或图表化。

## 必备章节结构

| 章节 | 内容要求 | 字数建议 |
|-----|---------|---------|
| 核心结论 | 一句话概括全文价值 | 50 字内 |
| 背景与动机 | 解决什么问题、为什么重要 | 200-300 字 |
| 核心方法/架构 | 技术细节、架构图、流程 | 500-800 字 |
| 适用场景 | 什么情况下使用、不适用场景 | 200-300 字 |
| 实验结果 | 完整数据表格、关键指标 | 按需 |
| 消融实验 | 各组件贡献（如有） | 按需 |
| 局限性与挑战 | 作者承认的问题 | 100-200 字 |
| 未来展望 | 发展方向、研究机会 | 100-200 字 |
| 实践建议 | 可操作行动指南 | 200-300 字 |
| 参考资源 | 论文、代码、官方文档链接 | 按需 |

## 格式规范

| 规范 | 要求 |
|-----|------|
| 段落长度 | 每段不超过 5 行 |
| 数据呈现 | 必须用表格，禁止纯文字罗列 |
| 架构说明 | 必须用图表（ASCII/Mermaid/SVG） |
| 对比分析 | 必须用表格 |
| 禁止事项 | 禁用 emoji；技术文档避免无关代码示例 |

## 文件命名规范

格式：`{主题}：{副标题}.md`

示例：
- `Agentic上下文工程：构建自进化AI系统的范式革命.md`
- `Claude Skill开发：从零到一的实践指南.md`

原则：去除平台标识；体现内容核心价值；使用中文冒号分隔主副标题。

## 输出保存与可选整理

视频分析报告必须保存到任务指定的输出 artifact 路径。若环境已安装并配置 `amagi-file-organizer`，可将其作为可选整理步骤；未配置时不得假定依赖存在。

可选配置示例：

```json
{
  "auto_organize": false,
  "organize_config": {
    "target_directory": "外部文件",
    "auto_create_categories": true,
    "naming_strategy": "content_based"
  }
}
```

工作流程：生成报告 -> 检查整理能力 -> 可选整理或手动保存 -> 主题命名。不得声称已调用不存在的整理工具。

## 质量检查清单

```text
□ 核心结论是否用一句话概括？
□ 关键价值是否用表格对比？
□ 架构是否用图表展示？
□ 实验数据是否完整（非摘录）？
□ 是否包含消融实验（如有）？
□ 是否包含局限性讨论？
□ 是否包含实践建议？
□ 段落是否都不超过 5 行？
□ 是否禁用了 emoji？
□ 参考资源是否完整？
```

## 错误处理与回退

| 错误 | 原因 | 解决方案 |
|-----|------|---------|
| yt-dlp 命令失败 | Cookie 过期或格式错误 | 重新导出 Cookie，或改用 Whisper |
| 字幕下载为空 | 视频无可用字幕 | 切换到 Whisper 转写 |
| WebFetch 403 | 平台反爬虫 | 切换到 web-reader / 浏览器 / 搜索补足 |
| Whisper 转写错误 | 音频质量差或模型问题 | 尝试更大模型或标注限制 |

回退链：yt-dlp 字幕 -> Whisper 转写 -> WebFetch 页面分析 -> web-reader -> 搜索相关资料。每一步失败都要记录原因。

## 模范文档参考

参考高质量文档标准：
- 完整 10 章结构。
- 从论文提取完整实验数据。
- 包含消融实验、局限性、实践建议和完整参考资源。
